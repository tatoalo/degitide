    How scheduling works
    1. We identify each stock or ETF’s listing exchange from DEGIRO. The fund’s underlying countries do not set its trading hours.
    2. Each account refreshes while any known held market is open, with a final refresh after close. Calendars include holidays, early closes, lunch breaks and daylight saving.
    3. The daily safety check refreshes snapshots at least 10 hours old. It also covers unknown markets. An evening closing sync can cover the next overnight Sure import.
    4. On restart, only overdue accounts catch up. Failed market syncs retry after 15, 30, 60, 120 and then 240 minutes; that backoff survives restarts.

    These rules apply in market-hours mode. Custom cron follows its own schedule. More frequent collection does not make delayed broker quotes live.

    How will Sure reach Degitide?

    Choose the address Sure’s server can use, even when your laptop is off.

    Connection type

    Use this address after connecting both apps to the private Docker network below.

    First time? Set up the network & Sure adapter

    1. Connect the containers. In your Degitide deployment directory, create the network once and add the Sure override to your usual Compose files: 

    docker network create --internal degitide-sure
docker compose -f docker-compose.yml \
  -f docker-compose.sure.yml up -d

    In Sure’s Compose file, attach both web and worker to that network. Keep their existing networks: 

    services:
  web:
    networks: [default, degitide]
  worker:
    networks: [default, degitide]
networks:
  degitide:
    external: true
    name: degitide-sure

    Sure must use self-hosted mode to allow this private HTTP address. Full Docker instructions ↗

    1. Make Degitide reachable. Use its HTTPS address, not the Sure URL or a temporary SSH tunnel. Both Sure services must be able to reach it.

    Add the hostname to DEGITIDE_ALLOWED_HOSTS in your Degitide configuration and recreate the app. For example, portfolio.example.com for https://portfolio.example.com. Keep any existing allowed hosts.

    2. Install the Sure adapter. This makes positions disappear from Sure when you sell them completely. Install it in both Sure web and worker, then recreate those services.

    Open adapter installation guide ↗

    3. Sync your accounts in Degitide. Complete a successful sync before importing into Sure.

    Accounts you add later stay private. Each currency appears separately in Sure.

    Holdings & their valueCash balances and investment trades are not included.

    Now switch to Sure.

    Keep this window open while you finish these steps.

    1. Copy your connection token

      Use once within 30 minutes. Treat it like a password.

    2. In Sure, open Add account → SimpleFIN

      Paste the token into the setup-token field and continue. You don’t need a paid SimpleFIN account or a Sure API key.

    3. Link your accounts as Investment / Brokerage

      Link each currency separately. Reconnecting? Choose your existing Sure accounts to avoid duplicates.

    Check the connection.

    Checking…

    Sure controls when it refreshes. Run a sync in Sure to try it now, then check the imported holdings there. A connection check can’t verify Sure’s account links or balances.

    Nothing showing up in Sure?
    • Finish linking every currency account in Sure and run a sync there.
    • Run a fresh Degitide sync if your saved holdings are more than 36 hours old or the last sync failed.
    • Check that Sure web and worker can reach the Degitide address and have the adapter installed.
    • Enable Sure’s background sync for automatic updates.

    Sync settings

    Market-hours settings

    Only refreshes snapshots at least 10 hours old. Choose a daily time before Sure imports. Changing it can affect the feed’s 36-hour freshness limit.

    Advanced safety schedule

    Automatic refreshes and retries are paused. A sync already running may finish. You can still sync manually.

    Changes apply immediately. Scheduled syncs continue when the dashboard is closed.
